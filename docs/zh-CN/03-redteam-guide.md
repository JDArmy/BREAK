# 红队使用指南

本文面向红队 / 渗透测试 / 攻防演练人员，讲清楚如何用 BREAK 从一条风险反向推演出完整的攻击路径：选低门槛入口 → 找实施工具 → 模拟攻击者角色 → 用真实案例复现手法。

> **使用边界声明**：本指南用于授权范围内的安全测试、攻防演练和安全研究。BREAK 知识库记录的是业务风险的抽象与公开案例，不提供具体漏洞利用代码。实际测试须在明确授权下进行。

## 核心思路：风险 → 攻击工具 → 威胁行为者 → 典型案例

红队用 BREAK 的链路是正向推演：从一条风险出发，找到直接造成该风险的攻击工具，再找到使用这些工具的威胁行为者，最后用典型案例核对真实手法。这正好是首页「攻击路径」视角可视化的方向。

```mermaid

  R["风险"] --> AT["攻击工具"] --> TA["威胁行为者"] --> C["典型案例"]
```

## 第一步：用攻击复杂度选择低门槛入口

红队选目标的优先级和防守方相反——防守方先防初级风险，红队也先测试初级风险。在风险列表页按攻击复杂度筛选初级风险，这些是攻击门槛低、无需特殊资源即可利用的点，最适合作为入口。

但要注意，初级不等于低危。一条初级风险可能门槛低但影响大（如账号注册自动化，门槛极低却支撑了整个黑产链条）。入口选择要结合风险的影响说明综合判断：门槛低 + 影响面广 = 最佳切入点。

## 第二步：沿直接致险关系找攻击工具

在风险详情页，风险与攻击工具的关系分两类：

- **直接造成的风险**：该工具直接造成的风险——这就是你要找的「打这个风险用什么工具」
- **间接支持的风险**：该工具间接支持的风险——辅助链条，可作横向扩展

点开任意攻击工具，了解它的用途、可造成或支持的风险，以及防守方会用哪些手段限制它。

**重点关注对应的规避手段**——它们说明这个工具可能被哪些措施检测或拦截。红队做路径设计时需要预判防御：如果所选工具会被现有措施直接识别，就需要调整工具或测试思路。

## 第三步：沿工具使用关系模拟攻击者角色

威胁行为者把工具和人串起来。详情页会区分这类角色是自建工具还是使用现成工具：

- **自建工具**：表示该角色有相应的开发能力
- **使用工具**：表示该角色的常见装备

威胁行为者描述的是「一类角色」的行为模式（羊毛党、黄牛党、卡商、内鬼、商业间谍、电诈团伙、数据掮客、勒索团伙等），不是具体组织或个人。阅读其详细描述能理解这类角色的动机、能力和典型作案模式，帮助你「站在攻击者视角」设计攻击剧本。

模拟时问自己三个问题：
1. 我现在扮演哪类威胁行为者？它的能力边界在哪？
2. 它是否具备我没考虑到的工具开发能力？
3. 它通常直接造成或间接支持哪些风险？我的目标风险是否在内？

## 第四步：用关系图谱「攻击路径」视角可视化

首页关系图谱的「攻击路径」视角把上述链路画成图：选一条风险作起点，展开直接造成该风险的攻击工具，再展开使用这些工具的威胁行为者，一眼看清「这条风险能被哪些工具打、这些工具被哪些角色用」。

「路径探索」视角更自由——可以从任意实体起步，沿着关系边自由游走，适合发现非显然的攻击链（比如某类威胁行为者使用的某个工具，恰好间接支持你目标业务的一个风险）。

## 第五步：用典型案例核对真实手法

风险、工具和角色的详情页都有「相关案例」区域，可以从中选择与你的目标最接近的案例：

- **刑事判决**：看判决书认定的犯罪手法、获利规模和组织分工
- **安全事件**：看已公开的事件经过和影响
- **学术研究**：看研究披露的攻击链和防御评估

分析案例时重点提取三要素：**时间线**、**主体**（谁干的）、**事实**（怎么实施的）。案例摘要用于快速了解事件，参考来源可用于进一步核对细节。

## 反向利用：从防守手段的局限性寻找绕过点

这是红队最该关注的内容。每条规避手段的局限性会说明它可能如何被绕过，以及在哪些场景容易误报。把目标业务的防御清单列出来，逐条分析这些局限：

- 「验证码可被打码平台识别」→ 验证码这条 AC01 防止手段失效，可绕过
- 「设备指纹可被模拟器伪造」→ 设备指纹失效
- 「行为分析对新账号误报高」→ 用新账号可绕过行为基线

把多条局限性说明叠加，往往能拼出一条完整的绕过链。这比盲目测试高效得多。

## 检查清单

红队规划一次授权测试时：

1. [ ] 确认授权范围，明确可测的业务和不可碰的红线
2. [ ] 在 BREAK 定位目标业务相关风险，按攻击复杂度选择初级入口
3. [ ] 找到直接造成目标风险的攻击工具，评估可用性
4. [ ] 查看限制所选工具的规避手段，预判会被哪些防御拦截
5. [ ] 选定扮演的威胁行为者，确认其能力覆盖目标风险
6. [ ] 用「攻击路径」/「路径探索」视角可视化完整链路
7. [ ] 查相关案例（优先刑事判决）核对真实手法
8. [ ] 阅读目标防御清单的局限性，定位测试重点
9. [ ] 输出攻击剧本：入口 → 工具 → 角色动机 → 预期被防点 → 绕过方案
