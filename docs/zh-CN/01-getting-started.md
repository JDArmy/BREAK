# 快速上手

BREAK（Business Risk Enumeration & Avoidance Knowledge）是一个面向业务安全的知识框架，把「业务风险」拆解为可枚举的六类实体，并用关系把它们串成可检索、可推演的网络。本文帮你在 5 分钟内建立整体认知。

## BREAK 是什么

BREAK 不是漏洞库，也不是 CVE 列表。它关注的是**业务逻辑被非预期利用造成的风险**——薅羊毛、撞库、支付欺诈、刷量刷榜、流程自动化滥用这类「业务侧」的攻击面，以及对应的规避手段、攻击工具、威胁行为者、行业术语和真实案例。

一句话定位：**风险是核心，其余五类实体都围绕风险组织**——规避手段防风险，攻击工具造风险，威胁行为者用工具造风险，行业术语解释风险，典型案例证实风险发生过。

## 六大实体一览

| 实体 | ID 格式 | 回答的问题 | 典型例子 |
|------|---------|-----------|---------|
| 风险 | R0001 | 攻击者利用业务逻辑做了什么坏事 | 账号注册自动化、支付渠道滥用 |
| 规避手段 | A0001 | 怎么防 / 怎么检测 | 验证码、设备指纹、行为分析 |
| 攻击工具 | AT0001 | 用什么实施攻击 | 打码平台、接码平台、代理池 |
| 威胁行为者 | TA0001 | 谁干的（角色分类） | 羊毛党、黄牛党、卡商 |
| 行业术语 | T0001 | 这个概念名词是什么 | 撞库、精养、多头借贷 |
| 典型案例 | C0001 | 发生过的一件事 | 某公安破获 DDoS 案 |

**定义边界是 BREAK 最看重的**：风险是「风险本身」而不是防御手段；规避手段是「具体手段」而不是泛泛概念；典型案例是「具体事件」而不是趋势综述。理解边界才能正确检索和归因。

## 三个核心入口

### 1. 首页：风险提示与关系图谱

首页展示当前高优先级风险提示卡，并提供关系图谱入口。关系图谱有四个视角：

- **风险关系**：风险之间的前置 / 共现 / 升级 / 变体关联
- **攻击路径**：风险 → 攻击工具 → 威胁行为者的正向推演
- **防御覆盖**：风险 → 规避手段的反向覆盖
- **路径探索**：自由探索任意起点的关系链

点首页任意风险卡可弹出风险抽屉，快速查看定义、影响和关联实体；点抽屉里的实体 ID 可跳转到对应列表详情页。

### 2. 知识库列表页

顶部「知识库」下拉提供六个实体的列表页（`/knowledges/{entity}/list`）。每个列表页是左右分栏：左栏实体列表（可搜索、可按维度筛选），右栏选中实体的完整详情。URL hash 可直接定位，例如 `/knowledges/risk/list#R0001`。

### 3. 站内搜索

按 `⌘K`（macOS）或 `Ctrl+K`（Windows）唤起全局搜索，跨六大实体模糊检索，支持关键词、别名、ID。搜索结果按实体类型分组，点击直达对应详情。

## 中英双语

站点支持中英双语。右上角语言切换器可切换全站语言，包括实体标题、描述、菜单和文档内容。

## 术语分类筛选

2.45.0 起，行业术语列表的分类筛选使用稳定分类 key，并根据当前语言显示中文或英文标签。切换语言不会改变筛选语义，URL、搜索与导出数据中的分类值也保持一致。
